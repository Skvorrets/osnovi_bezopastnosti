# ОТЧЁТ
## по прохождению этапа Stepik «Базовые сетевые протоколы»

### Цель работы
Изучение принципов работы сетевых протоколов и механизмов защиты передачи данных.

## 1. Протоколы прикладного уровня
В ходе прохождения курса были изучены сетевые протоколы прикладного уровня. Для выполнения задания был выбран протокол HTTPS, который используется для защищённой передачи данных между клиентом и сервером.

## 2. Транспортный уровень TCP
Во время выполнения тестового задания был определён уровень работы протокола TCP. В результате было установлено, что TCP относится к транспортному уровню модели TCP/IP.

## 3. Протокол HTTP
Было рассмотрено назначение протокола HTTP. В ходе выполнения задания определено, что HTTP выполняет передачу данных между клиентом и сервером в открытом виде.

## 4. Структура HTTPS
На данном этапе была изучена структура протокола HTTPS и механизм работы TLS. Было определено, что HTTPS включает фазу рукопожатия и фазу передачи данных.

## 5. DNS и сопоставление доменных имён
Во время прохождения задания была изучена работа DNS-сервера. Было установлено, что DNS выполняет сопоставление IP-адресов доменным именам.

## 6. Модель TCP/IP
В ходе выполнения теста была выбрана корректная последовательность уровней модели TCP/IP. Также были рассмотрены функции прикладного, транспортного, сетевого и канального уровней.

## Выводы
В ходе выполнения работы были изучены основные сетевые протоколы, механизм работы DNS, TCP/IP, HTTP и HTTPS.
