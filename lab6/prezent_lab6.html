Цель работы

  • Развить навыки администрирования ОС Linux, получить первое практическое знакомство с технологией SELinux и проверить её работу совместно с веб-сервером Apache.

Проверка режима SELinux

  • getenforce -> Enforcing
  • sestatus -> политика targeted, режим enforcing
  • Подтверждена корректная конфигурация лабораторного стенда

Apache и контекст безопасности

  • Проверена работа службы httpd
  • Процессы Apache работают в домене httpd_t
  • Контекст определён командами ps auxZ | grep httpd

Контексты файлов в /var/www

  • Каталог /var/www/html имеет тип httpd_sys_content_t
  • Создан файл test.html
  • По умолчанию он получает контекст, доступный Apache

Нарушение контекста и отказ доступа

  • Контекст test.html изменён на samba_share_t
  • После этого доступ по URL /test.html запрещён
  • SELinux блокирует Apache несмотря на обычные права файла

Анализ журналов и порта 81

  • В журналах появляются AVC-denied сообщения
  • Apache не может bind к порту 81 без разрешения SELinux
  • Проблема устранена через semanage port

Результат и выводы

  • Порт 81 добавлен в http_port_t
  • Контекст файла возвращён к httpd_sys_content_t
  • Веб-сервер снова отдаёт страницу test.html
