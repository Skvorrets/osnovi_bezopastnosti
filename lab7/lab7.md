## 1. Подготовка программы для шифрования и дешифрования

На первом этапе был создан Python-скрипт gamma.py.

### Команды
```bash
nano gamma.py
python3 gamma.py
```

Была подготовлена программа, выполняющая XOR-операцию между символами текста и ключа.

---

## 2. Получение шифротекста

После запуска программы был получен шифротекст.

### Команды
```bash
python3 gamma.py
```

В результате применения операции XOR был сформирован шифротекст.

---

## 3. Дешифрование сообщения

На следующем этапе был реализован процесс обратного преобразования шифротекста.

### Команды
```bash
python3 gamma.py
```

Использование того же ключа позволило полностью восстановить исходный текст.
